* org-files-db.el

[[https://www.gnu.org/licenses/gpl-3.0][https://img.shields.io/badge/License-GPL%20v3-blue.svg]]
[[https://github.com/hubisan/org-files-db.el/actions/workflows/ci.yml][https://github.com/hubisan/org-files-db.el/actions/workflows/ci.yml/badge.svg]]

Emacs interface for [[https://github.com/hubisan/org-files-db][org-files-db]].

The package is at an early stage.  The repository currently contains the
package, test, lint, and continuous-integration skeleton but no public commands.

** Requirements

- Emacs 29.4 or newer
- [[https://github.com/hubisan/org-files-db][orgfdb]] available in =PATH=, once command integration is implemented
- [[https://emacs-eask.github.io/][Eask]] for development

** Repository structure

#+begin_src text
  lisp/org-files-db.el       Package entry point
  tests/org-files-db-test.el Buttercup tests
  Eask                       Package and development dependencies
  Makefile                   Local development commands
#+end_src

The project-specific AI instructions are stored in
[[./.project/agents/AGENTS.md][.project/agents/AGENTS.md]].

** Development

Install development dependencies:

#+begin_src shell
  make setup
#+end_src

Run the same checks as continuous integration:

#+begin_src shell
  make ci
#+end_src

The checks include byte-compilation, package linting, source linting, and
Buttercup tests.

Other useful commands:

#+begin_src shell
  make test
  make lint
  make compile
  make package
  make clean
  make emacs
#+end_src
