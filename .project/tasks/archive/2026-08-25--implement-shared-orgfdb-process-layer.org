Implement Step 2 of the ~org-files-db.el~ rebuild.

* Planning

** Problem summary

The rebuilt package resolves named configurations but cannot execute ~orgfdb~ yet.

All short-lived CLI commands need one synchronous process implementation.

** Goals

- Resolve ~org-files-db-executable~ to an executable file.
- Resolve configuration names to readable files.
- Run ~orgfdb~ without a shell.
- Pass each CLI argument as a separate process argument.
- Capture stdout and stderr separately as UTF-8.
- Report runtime and CLI usage errors with stderr text.
- Provide raw-output and JSON-output call helpers.
- Provide one helper for default or prefix-selected configurations.
- Rebuild ~org-files-db-check-setup~ for named configurations.

** Non-goals

- Do not implement watcher processes.
- Do not implement ~PresentationSpec~.
- Do not implement query completion.
- Do not implement Rust view registration or reads.
- Do not add asynchronous short-lived CLI calls.

** Architecture

Keep process execution and configuration resolution in ~org-files-db-process.el~.

Use one low-level synchronous process function. Build raw and JSON call helpers on this function.

Use ~make-process~ with a command list. Do not build a shell command string.

Keep the watcher outside this process path because the watcher is long-lived.

** Execution plan

1. Add process and configuration tests for the Step 2 interface.
2. Add executable resolution and configuration argument helpers.
3. Add the synchronous process runner and CLI error types.
4. Add raw-output and JSON-output helpers.
5. Add default and prefix configuration selection.
6. Add ~org-files-db-check-setup~.
7. Run the available checks and review the changed code.

** Risks & assumptions

The process runner must remain small because query and view modules will reuse it.

The setup check uses the read-only ~orgfdb status~ command for the selected configuration.

The process module now owns all short-lived CLI execution.

Interactive commands can use the default configuration or call the shared prefix-selection helper.

~org-files-db-check-setup~ checks the selected configuration with ~orgfdb status --format json~.
