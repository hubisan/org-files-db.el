#+TITLE: Repository-specific AI Instructions
#+STARTUP: showall

* Preferred checks

- Run all checks with:

  #+begin_src sh
  make ci
  #+end_src

- Use ~make compile~, ~make lint~, or ~make test~ to investigate failures.
- Run ~make setup~ after changing development dependencies in ~Eask~.
- Add or update Buttercup tests for behaviour changes.
- Stub ~orgfdb~ and external services in tests.
- Keep GitHub Actions consistent with ~make ci~.

* Project structure

- Package files belong in ~lisp/~.
- Tests belong in ~tests/~.
- Test fixtures belong in ~tests/fixtures/~.
- User-visible changes belong in ~CHANGELOG.org~.
- The package communicates with ~orgfdb~ through its CLI and JSON output.
- Do not access the SQLite database directly.

* Coding style

- Prefix public symbols with ~org-files-db-~.
- Prefix internal (private) symbols with ~org-files-db--~.
- Keep process execution, JSON decoding, transformation, and presentation separate.
- Pass process arguments separately; do not build shell command strings.
- Stub external processes in unit tests.
- Avoid unrelated formatting changes.

* Folders/Files to ignore

- Ignore generated Eask state, dependencies, package archives, ~*.elc~, editor backups, ~node_modules/~, and temporary test output.
